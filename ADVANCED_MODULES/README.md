# Advanced Modules A–L

Maintain one record per module A–L using the exact scope in MASTER_COURSE_PLANNER.md. A module may span multiple lessons. Track topic coverage, command/practical evidence, quiz/interview practice, gaps and next action. Bootcamp completion does not complete the advanced course.

## Screenshot and visual-asset standard

- Store relevant module captures in `ADVANCED_MODULES/assets/`, creating the folder only when an asset is added.
- Link each asset from the relevant module lesson with relative Markdown paths, meaningful alt text and a caption.
- Use screenshots for real Git internals tools, advanced GitHub settings/workflows, diagnostics and UI states when a capture communicates details better than editable text or Mermaid.
- Label authentic captures versus instructor mock-ups and illustrative terminal output. Never imply that a demonstration is learner evidence.
- Redact personal/private information and credentials; credit external assets and respect licences.
- Keep images legible and current. Prefer Mermaid source for diagrams and short GIFs only for meaningful motion, with a static alternative.
- Verify links and rendered images after committing.
