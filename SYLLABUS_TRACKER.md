## Evidence rules

- A lesson explanation alone is not proof of practical completion.
- Mark Introduced when the topic has been taught.
- Mark Practised only after the learner attempts it and provides evidence of the attempt.
- Mark Verified only after understanding and practical application have both been checked.
- Keep instructor-demonstrated commands distinct from commands run by the learner.
- Link commit, PR, workflow run or learner-provided terminal output when available.

## Presentation rule

Do not copy this tracker into lesson bodies. A lesson should teach; this file should track.
