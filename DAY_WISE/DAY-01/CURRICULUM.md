# Day 1 — Foundations and first repository

## Syllabus

1. Why version control exists: change history, collaboration, rollback, traceability and reliable backups.
2. Version-control models: local, centralised and distributed; Git's distributed model and its trade-offs.
3. Git vs GitHub and hosting platforms: version-control tool vs hosting/collaboration service.
4. Repository anatomy and workflow areas: working directory/worktree, staging area/index, local repository and remote repository.
5. File states and transitions: untracked, tracked, modified, staged, committed; snapshots, parent commits, object IDs, branches and HEAD.
6. Install and configure Git on Windows: Git for Windows, Git Bash, version checks, identity and configuration scopes; PowerShell/CMD differences where useful.
7. Create and inspect the first repository: `mkdir`, `cd`, `git init`, `git status`, `git add`, `git commit`, `git log` and `git diff`.
8. Day 1 practical, troubleshooting, knowledge check and interview review (only when the learner explicitly opts in to the relevant activity).
