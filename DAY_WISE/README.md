# Day-wise Learning Records

One Markdown record per bootcamp day. A day is a curriculum unit, not a one-session deadline. Keep unfinished syllabus items visible across chats.

Each day record captures exact syllabus topics/status, lesson notes/examples, commands demonstrated vs actually run, guided and independent practicals/evidence, quiz and interview preparation, revision needs, blockers and exact continuation point.

Use the same progress labels as SYLLABUS_TRACKER.md. Do not mark a day complete until its syllabus, practicals, quiz and interview preparation have been addressed.
