# Supplementary Notes

This folder preserves useful learning notes from conceptual discussions that support the Git & GitHub course but are **not themselves core syllabus lessons**.

These notes are supplementary references. They do not change the bootcamp, advanced-module or project sequence, and they do not change learner progress or verification status.

## Notes

- [Windows command line, Bash, Git Bash, MSYS2 and MinGW](WINDOWS_COMMAND_LINE_AND_GIT_BASH.md) — shells vs terminals, GNU/Unix/Linux context, executable utilities such as `ls`, PATH lookup, MSYS runtime, MSYS2, MinGW-w64, Windows path handling and the GCC compilation pipeline.

## Saving policy — explicit request only

Notes in this folder are saved **only when the learner explicitly asks** for a supplementary discussion or specific material to be preserved here. Do not add or update notes automatically, even when a discussion is substantial or useful. Requests to continue or explain a concept are not save requests.

When explicitly authorized, update an existing note where possible; create a new file only for a substantial, distinct subject and link it from this index. Keep supplementary notes separate from formal syllabus and progress records. Saving a note is not evidence of practical completion or topic verification.
## Conventions

- Mermaid diagrams are included as editable source and render on GitHub.
- Commands and paths are illustrative unless explicitly identified as learner-provided evidence.
- Installation paths can vary by version and installation choices.
- These notes explain concepts; they do not assign exercises or imply that commands were run by the learner.
- When later discussions add or correct concepts, update the relevant note rather than creating duplicate files.


## Selective capture standard
Even when the learner explicitly requests a supplementary note, preserve only the durable, useful points needed for later reference—key concepts, distinctions, commands, representative examples, diagrams and important cautions. Do not save a transcript, every follow-up, repeated explanations or incidental details. Prefer updating an existing note instead of creating duplicates. The explicit-save requirement still applies: supplementary discussions are never added automatically.
