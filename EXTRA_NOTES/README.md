# Supplementary Notes

This folder preserves useful learning notes from conceptual discussions that support the Git & GitHub course but are **not themselves core syllabus lessons**.

These notes are supplementary references. They do not change the bootcamp, advanced-module or project sequence, and they do not change learner progress or verification status.

## Ongoing capture policy

Future important discussions that are supplementary to the formal course should be documented here. Update an existing topic note when possible; add a new Markdown file only for a substantial, distinct subject and link it from this index. Preserve key explanations, corrections, comparisons, examples and editable Mermaid diagrams where useful. Keep these references separate from formal syllabus and learner-progress records. Saving a note is not evidence of practical completion or topic verification.

## Conventions

- Mermaid diagrams are included as editable source and render on GitHub.
- Commands and paths are illustrative unless explicitly identified as learner-provided evidence.
- Installation paths can vary by version and installation choices.
- These notes explain concepts; they do not assign exercises or imply that commands were run by the learner.
- When later discussions add or correct concepts, update the relevant note rather than creating duplicate files.
